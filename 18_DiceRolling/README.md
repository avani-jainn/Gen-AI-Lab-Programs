# Program 18: Dice Rolling Game

## Aim
To create a simple dice rolling game using Python.

## Description
This program simulates rolling a dice and generates a random number between 1 and 6.

## Concept Used
- Python
- Random module
- Loops
- Conditional statements
- User input

## How It Works
The user chooses whether to roll the dice. The program generates a random number from 1 to 6 for every roll.

## Output
The program displays the randomly generated dice value.

## Conclusion
A simple dice rolling game was successfully created using Python.
