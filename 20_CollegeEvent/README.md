# Program 20: College Event Landing Page

## Aim
To design a simple college event webpage using HTML, CSS, and JavaScript.

## Description
The webpage displays information about a college technical event and its activities.

## Concept Used
- HTML
- CSS
- JavaScript
- CSS hover effect
- Theme changing using JavaScript

## Features
- College event heading
- Event activity cards
- Hover effect
- Change Theme button

## How It Works
The webpage displays different technical events. When the user clicks the Change Theme button, JavaScript changes the webpage theme.

## Output
A college technical event webpage is displayed in the browser.

## Conclusion
A simple interactive college event webpage was successfully created.
