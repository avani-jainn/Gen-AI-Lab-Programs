# Program 22: College Event Website Deployment

## Aim
To create and deploy a simple college event website using GitHub and a web hosting platform.

## Description
A college event website was created and uploaded to GitHub. The website was then deployed so that it could be accessed through a live link.

## Concept Used
- HTML
- CSS
- GitHub
- Repository
- Web deployment
- README documentation

## Steps Performed
1. Created the college event website.
2. Created a GitHub repository.
3. Uploaded the website files.
4. Added a README file.
5. Deployed the website using a hosting platform.
6. Tested the live website.

## Output
The college event website was successfully uploaded and deployed.

## Conclusion
The process of creating, uploading, and deploying a website was successfully performed.
