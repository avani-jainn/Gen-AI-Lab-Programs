# Program 16: Expense Tracker

## Aim
To create a simple expense tracker using C.

## Description
This program allows the user to add expenses, view all recorded expenses, and calculate the total expense.

## Concept Used
- Arrays
- Strings
- Structures
- Menu-driven program
- Input and output

## How It Works
The user enters the expense name and amount. The program stores the details and displays all expenses along with the total amount.

## Output
The program displays the entered expenses and the total expense.

## Conclusion
A simple expense tracking system was successfully created using C.
