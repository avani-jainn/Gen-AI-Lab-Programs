# Program 17: Matrix Analyzer

## Aim
To perform basic operations on a 3 × 3 matrix using Java.

## Description
The program accepts a 3 × 3 matrix and calculates the sum of its rows, columns, and diagonals.

## Concept Used
- Two-dimensional arrays
- Loops
- Java input/output
- Matrix operations

## How It Works
The program takes nine values as input and stores them in a 3 × 3 matrix. It then calculates row sums, column sums, and diagonal sums.

## Output
The program displays the matrix and the calculated sums.

## Conclusion
Basic matrix operations were successfully performed using Java.
