# Program 15: N-Queens Using Backtracking

## Aim
To solve the N-Queens problem using the backtracking technique.

## Description
The N-Queens problem places N queens on an N × N chessboard so that no two queens attack each other.

## Concept Used
- Backtracking
- Recursion
- Chessboard
- Constraint checking

## How It Works
The program places queens row by row. If a queen cannot be placed safely, the program goes back and tries another position.

## Output
The program displays a valid arrangement of 8 queens on the chessboard.

## Conclusion
The N-Queens problem was successfully solved using backtracking.
