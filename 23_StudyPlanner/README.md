# Program 23: Study Planner Using Bolt.new

## Aim
To create a simple study planner application using Bolt.new.

## Description
A study planner was created to help students organize their subjects and study tasks.

## Concept Used
- AI-assisted development
- Web application
- User interface
- Task management
- Testing and deployment

## Features
- Add study tasks
- Display subjects/tasks
- Simple and user-friendly interface
- Task organization

## How It Works
The application was generated and customized using Bolt.new. The features were tested and necessary changes were made to improve the application.

## Output
A functional study planner web application was created.

## Conclusion
A simple study planner was successfully developed using Bolt.new.
