# Program 21: Online Poll

## Aim
To create a simple online polling webpage using HTML, CSS, and JavaScript.

## Description
The webpage allows users to select their favourite activity from different options.

## Concept Used
- HTML
- JavaScript
- Buttons
- DOM manipulation
- Event handling

## How It Works
The user selects an activity by clicking a button. JavaScript displays the selected activity on the webpage.

## Output
The selected activity is displayed below the buttons.

## Conclusion
A simple interactive online poll was successfully created using HTML and JavaScript.
