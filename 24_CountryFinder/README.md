# Program 24: Country Information Finder

## Aim
To create a web application that displays country information using a REST API.

## Description
The application allows the user to enter a country name and fetch its information using the REST Countries API.

## Concept Used
- HTML
- JavaScript
- Fetch API
- REST API
- Async/Await
- Error handling

## Features
- Country search
- Country name
- Capital
- Population
- Error message for invalid country

## How It Works
The user enters a country name and clicks the Search button. JavaScript sends a request to the REST Countries API and displays the received information.

## Output
The application displays the country name, capital, and population.

## Conclusion
A country information finder was successfully created using JavaScript and a REST API.
